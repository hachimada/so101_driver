# スライダーGUI

[English](../so101_gui.md) | **日本語**

スライダーGUIでは、フォロワーの6軸を操作し、各モーターの状態を確認できます。

## 起動

[機体の設定](so101_setup.md)と[キャリブレーション](so101_calibration.md)を済ませてから実行します。

```bash
ros2 launch so101_driver follower_slider_control.launch.py
```

制御を許可した状態（`allow_writes`の既定値は`true`）で[フォロワーノード](so101_follower.md)も起動します。
別の設定ファイルを使う場合は`params_file:=/path/to/follower.yaml`を指定します。

## 操作

1. 現在角度が表示され、**Ready to start**になるのを待ちます。
2. **Start control**を押します。現在姿勢が初期目標になります。
3. スライダーまたは数値欄で目標角度を指定します。表示単位は度です。
4. 操作を止めるときは**Stop**を押します。現在位置を保持します。
5. 終了するときは腕を支え、**Release torque and quit**を押します。

現在角度と目標角度は別々に表示します。
各スライダーの範囲は、キャリブレーションで記録した範囲とサーボの可動範囲から決まります。

**Stop**とウィンドウを閉じる操作では、トルクはONのままです。
**Release torque and quit**は、全軸のトルク解除を確認してから画面を閉じます。
解除に失敗した場合は理由を表示するので、接続状態を確認して再試行してください。
GUIを閉じると、フォロワーノードも終了します。

## ホーム位置

| ボタン | 動作 |
|---|---|
| Set current pose as home | その時点の実測姿勢を保存。すでに登録済みの場合は置き換え |
| Go home | 制御開始後、登録した姿勢へ移動 |

登録は制御開始前にも行えます。全関節の現在値が取得でき、スライダーの範囲内にあることが条件です。
ホーム位置はキャリブレーションJSONに保存され、次回起動時も使用できます。
キャリブレーションし直した場合は、ホーム位置も登録し直してください。

ホームへの移動は**Stop**で中断できます。
移動速度・加減速は通常のスライダー操作と共通です。
[動作設定](so101_follower.md#動作設定)を参照してください。

## モーターの状態

画面下部で、トルク状態・速度・電流・デューティー比・電圧・温度・異常を確認できます。
関節の行を選ぶと、サーボ内の目標位置、モデル情報、保護設定などの詳細を表示します。
制御開始前も確認できます。

表示の意味と単位は[モーター状態の見方](so101_motor_monitor.md)を参照してください。

## トラブルシューティング

| 表示・状況 | 対処 |
|---|---|
| 現在姿勢が指令範囲外 | 表示された関節を確認し、スライダーの範囲内の姿勢に合わせる |
| 制御開始に失敗 | 画面とターミナルに表示された理由を確認する |
| 通信異常でスライダーが無効 | 接続の復旧後に**Start control**を押す |
| **Go home**が無効 | ホームを登録し、制御を開始する。理由はボタンのツールチップで確認できる |
| `Follower control is not allowed` | フォロワーが`allow_writes:=false`で起動している |

制御開始の条件や停止時の動作は[フォロワー制御インターフェース](so101_follower.md)を参照してください。
